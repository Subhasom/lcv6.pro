Trend, volatility and volume on one chart.

LCV6 is an indicator for TradingView. It compares the current market with similar moments in the past, confirms direction with a trend line, and marks where volatility and unusually large volume show up.

Activate the trial

LCV6 Trial shows nothing until it has an activation code. Each code carries its own expiry date.

  1. Add LCV6 Trial to your chart

    Open the script on TradingView and add it to any chart.

    Open LCV6 Trial on TradingView

  2. Request an activation code

    Fill in the short form. You get back a numeric code.

    Request an activation code

  3. Enter the code in the settings

    Open the indicator's settings, go to Inputs and type the code under Activation Code. The chart fills in straight away.

Before you use it

Where it works
On TradingView, on any symbol and timeframe. It suits commodities and intraday charts best.
What you can change in the trial
The V-Window and Liquidity Volume settings. Everything else runs at its defaults.
Summary table
A table on the chart backtests the signals over the loaded bars, with fills at the next bar's open and trading costs included.
Alerts
14 alerts, including Buy, Sell, Break, V-Window open and close, and green or red bubbles.
Bubbles on recent bars only
Bubbles are built from lower-timeframe data, which TradingView provides for recent bars only.
What it does not do
LCV6 does not predict prices. Its signals follow the trend and are sometimes wrong. Use it to read a chart, then make your own decision.
